# Planning RDV

Site web de prise de rendez-vous connecté à Google Agenda, avec base de données clients et récapitulatif des rendez-vous.

## Stack

- **Front** : React + TypeScript (`client/`)
- **Back** : Node.js + TypeScript (`server/`)

## Structure

```
client/   Application React
server/   API
docs/     Schéma d'architecture, fiches de preuve, comptes rendus
```
